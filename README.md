# MSX Home Server Studio

Интерактивный конструктор, эмулятор и сервер параметров запуска для **Media Station X** (Smart TV: Samsung Tizen, LG webOS, Android TV).

---

## 🚀 Быстрый запуск в Proxmox VE (LXC контейнер)

### 1. Создание контейнера в Proxmox VE
В веб-интерфейсе Proxmox VE нажмите **Create CT**:
* **OS Template:** `Debian 12` (bookworm) или `Ubuntu 24.04` (минимальный шаблон).
* **Disks:** `4–8 GB` (достаточно с запасом).
* **CPU:** `1 vCPU`.
* **Memory:** `512 MB – 1024 MB` RAM, `512 MB` Swap.
* **Network:** Рекомендуется задать **статический IP-адрес** (например, `192.168.1.50/24`, Gateway: `192.168.1.1`), чтобы телевизор всегда обращался по одному неизменному адресу.

### 2. Клонирование и автоматическая установка
Войдите в консоль созданного LXC-контейнера (или подключитесь по SSH) и выполните:

```bash
# Клонируем репозиторий
git clone https://github.com/webprizma/msx.git /opt/msx
cd /opt/msx

# Запускаем автоустановщик (ставит Node.js, собирает проект и регистрирует systemd службу)
chmod +x deploy-lxc.sh
./deploy-lxc.sh
```

Скрипт автоматически:
1. Установит Node.js 20 LTS и зависимости.
2. Соберет проект (`npm run build`).
3. Создаст и включит системную службу `msx-server.service`, которая будет автоматически подниматься при загрузке контейнера в Proxmox.

---

## 📺 Подключение телевизора

1. На телевизоре запустите приложение **Media Station X**.
2. Перейдите в **Settings (шестеренка в правом верхнем углу)** ➔ **Start Parameter** ➔ **Setup**.
3. Введите адрес вашего LXC сервера:
   ```
   http://192.168.1.50:3000/start.json
   ```
   *(замените `192.168.1.50` на фактический IP-адрес вашего контейнера)*.
4. Нажмите **Done (Готово)**.

---

## 🛠 Управление службой в LXC

* Посмотреть статус: `systemctl status msx-server`
* Перезапустить: `systemctl restart msx-server`
* Посмотреть логи: `journalctl -u msx-server -f`

---

## 🐳 Запуск через Docker / Docker Compose (опционально)

Если внутри контейнера Proxmox у вас развернут Docker:

```bash
docker compose up -d --build
```
Сервер будет доступен на порту `3000`.
